# 🧠 About The Project

This project was created as a **hands-on learning experience** to deeply understand how **React and Redux** work together in modern frontend applications.

The application allows users to search and explore:

* 📷 Photos
* 🎬 Videos
* 🎞️ GIFs

using real-time integrations with:

* **Unsplash API**
* **Pexels API**
* **Giphy API**

The primary goal of this project was not just building a media app — but understanding the internal workflow of Redux:

* Global state management
* Unidirectional data flow
* Reducers and actions
* Redux Toolkit slices
* State-driven UI updates
* Component re-rendering behavior
* Scalable frontend architecture

---

# ✨ Google Stitch AI Experience

One of the most exciting parts of this project was experimenting with **Google Stitch AI** for UI inspiration.

Honestly, it was surprisingly impressive.

The layouts, spacing, typography, gradients, and modern interface ideas generated by Stitch felt incredibly polished and production-ready. It significantly accelerated the design process and introduced creative UI concepts that made the project visually much stronger while allowing me to focus primarily on understanding Redux mechanics.

# ⚙️ Installation

## Clone The Repository

```bash
git clone https://github.com/shadows12-star/React-Redux-Project.git
```

## Navigate Into The Project

```bash
cd React-Redux-Project
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

---

# 🔐 Environment Variables

Create a `.env` file in the root directory:

```env
VITE_UNSPLASH_KEY=your_unsplash_access_key
VITE_PEXELS_KEY=your_pexels_api_key
VITE_GIPHY_KEY=your_giphy_api_key
```

> ⚠️ Never expose your API keys publicly.

# 🔑 Redux Concepts Practiced

## 🏪 Store Configuration

```js
const store = configureStore({
  reducer: {
    collections: collectionReducer,
    search: searchReducer,
  },
});
```

---

## 🧩 Slice Architecture

```js
const searchSlice = createSlice({
  name: 'search',
  initialState: {},
  reducers: {}
});
```

---

## 🔄 Dispatching Actions

```js
dispatch(setQuery('nature'));
```

---

## 📡 Accessing Global State

```js
const query = useSelector((state) => state.search.query);
```
